# 💊 Pharmacy Management System - VB.NET

A complete desktop-based Pharmacy Management System developed with Visual Basic .NET and Windows Forms.

### Features
- Secure User Login System (Admin & Staff)
- Drug Inventory Management - Add, Update, Delete medicines
- Automated Billing System with quantity calculation
- Patient / Customer Management
- Prescription Handling
- Total Bill Calculation (Quantity x Unit Price)
- DataGridView for viewing medicines and bills
- Billing receipt generation

### Technologies Used
- Language: Visual Basic .NET (VB.NET)
- IDE: Microsoft Visual Studio
- Framework: .NET Framework / Windows Forms
- Database: SQL Server / MS Access

### How to Run the Project
1. Clone or download this repository
2. Open Tsample 009.sln in Visual Studio
3. Press F5 or click Start to run
4. Login and start managing pharmacy
